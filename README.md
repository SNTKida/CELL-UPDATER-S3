# 🎮 CELL Updater S3

Sistema de gestión asistido por inteligencia artificial para la sincronización de binarios en entornos de emulación (RPCS3).

> **⚠️ Nota:** Este proyecto se encuentra en fase **Alpha 0.1** y está siendo desarrollado como requisito para la defensa de tesis de grado de la carrera de Ingeniería de Sistemas en la Universidad de Oriente (UDO), Venezuela.

## 🚀 Características Principales
- **Dos sistemas en uno**: Cell Updater S3 es el cascaron e interfaz que trabaja en coordinacion con AMAZONA, un agente de IA potenciada por LLMs para traducir changelogs a lenguaje simple y mantener el emulador RPCS3 actualizado.
- **Reconocimiento del usuario**: AMAZONA guarda tu nombre y te reconoce siempre y cuando este CellUpdater S3 conectado a internet.
- **Detección Inteligente de Hardware:** Análisis completo de CPU, RAM, GPU (Dedicada e Integrada) y Almacenamiento.
- **Agente de IA Multi-Proveedor:** Integración flexible con modelos de lenguaje (DeepSeek, Qwen, Claude, etc.) para generar resúmenes inteligentes de los cambios (changelogs) de cada actualización.
- **Actualización No Destructiva:** Preserva automáticamente los datos del usuario (`dev_hdd0`, configuraciones, caché) durante el proceso de actualización.
- **Ejecución en Segundo Plano:** Sistema de notificaciones nativas y programación de tareas (Timer de 24h) para mantener el emulador al día sin interrumpir al usuario.
- **Interfaz Moderna:** Diseño profesional con múltiples temas visuales (PS3 Fat, Slim, Modo Claro, Midnight Red).

## 🛠️ Requisitos del Sistema

- Windows 10 / 11 (64 bits)
- Conexión a Internet (para consultas a GitHub y APIs de IA)
- RPCS3 instalado en el sistema
